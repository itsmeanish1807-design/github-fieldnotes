# GitHub Fieldnotes

A developer intelligence platform to explore, analyse, and compare GitHub profiles.

### Features
- GitHub profile exploration
- Developer statistics and activity insights
- Programming language analysis
- Developer comparison
- Saved developer profiles

### Tech Stack
React · Vite · Node.js · Express.js · MongoDB · GitHub REST API

### Run Locally
```bash
git clone https://github.com/itsmeanish1807-design/github-fieldnotes.git
cd github-fieldnotes
```

Install dependencies in both `client` and `server`, configure environment variables, and start the development servers.
